# 🧮 NeoCalc PRO - Expandable Precision Calculator & Smart Converter

A modern, high-precision web calculator and expandable multi-category unit converter designed with glassmorphism aesthetics, dynamic ambient glows, Web Audio API sound feedback, responsive layout, and interactive calculation history.

## ✨ Features

- 💎 **Modern Glassmorphic UI**: Backdrop blur, ambient gradient floating orbs, smooth borders, and tactile neumorphic buttons.
- 📐 **Expandable Layout & Modes**:
  - **Standard Calc**: Compact single-column calculator.
  - **Smart Converter**: Dedicated unit conversion dashboard.
  - **Dual Split View**: Side-by-side expandable workspace with real-time data bridging!
- 🔄 **Multi-Category Smart Unit Converter**:
  - 📏 **Length**: Meters, Kilometers, Centimeters, Millimeters, Miles, Yards, Feet, Inches
  - ⚖️ **Mass / Weight**: Kilograms, Grams, Milligrams, Metric Tons, Pounds, Ounces
  - 🌡️ **Temperature**: Celsius (°C), Fahrenheit (°F), Kelvin (K)
  - 💾 **Digital Data**: Bytes, KB, MB, GB, TB
  - ⚡ **Speed**: km/h, mph, m/s, Knots
  - ⏳ **Time**: Seconds, Minutes, Hours, Days, Weeks, Years
- ⇄ **Two-Way Reactive Conversion**: Type in either field, swap units instantly, or tap quick preset chips.
- 📥 **"Use in Calc" Integration**: Transfer converted figures straight into the calculator display.
- 🌓 **Dark & Light Mode**: Instant toggle with persistent preferences saved to `localStorage`.
- 🔊 **Synthesizer Audio Feedback**: Real-time auditory feedback powered by Web Audio API.
- 📜 **Calculation History Drawer**: Keeps track of recent equations; click any previous result to restore.
- ⌨️ **Full Physical Keyboard Support**: Numbers, operators, Enter, Backspace, Escape.
